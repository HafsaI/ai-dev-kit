Delegate to the `stack-code-reviewer` agent to review the current diff (`git diff` against the base branch or last commit). Relay its findings to the user as-is — ranked most-severe first. Do not apply any fixes yourself unless the user asks you to after seeing the findings; this command is a report, not an auto-fix.
